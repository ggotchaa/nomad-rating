# Памятка помощника (судья, администратор зала)

Вы видите в кабинете клуба только разделы, на которые организатор дал права. Действия записываются в журнал клуба.

## Администратор зала (право «Брони»)
- «Журнал броней»: день или неделя. Отмечайте «Пришёл» / «Не пришёл» — неявки видны организатору в карточке игрока.
- Звонок по телефону: нажмите на пустую ячейку, выберите игрока или впишите имя и телефон гостя, длительность → «Забронировать».
- Перенос: перетащите бронь или откройте её → «Перенести…» → выберите вариант. Игрок получит уведомление.
- Блок «Брони, требующие решения» появляется, когда турнир или закрытие зала пересекается с бронями. Решите каждую: перенести или отменить.

## Судья (право «Проведение»)
1. «Турниры» → турнир → «Проведение».
2. Чек-ин: откройте «Показать QR» на экране зала или отмечайте игроков вручную.
3. Проверьте посев и нажмите «Старт».
4. Экран столов: план зала показывает, кто где играет (зелёный — играют, оранжевый — вызваны). Из очереди нажимайте «Вызвать» — игрок получит вызов и ответит «Иду» / «Не могу».
5. Ввод счёта: большие кнопки, работает без интернета — счёт отправится, когда сеть появится.
6. Особые ситуации (неявка, отказ, снятие) — через карточку матча с указанием причины.
